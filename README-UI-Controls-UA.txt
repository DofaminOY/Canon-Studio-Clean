Canon Studio — оновлення перемикачів (для проєкту з інтерфейсом 4.2)

Зміни:
- Об'єднано «Якість» і «Пріоритет швидкості»: Draft / Standard / High — один параметр.
- Активний варіант: темно-зелений фон, білий текст, галочка. Неактивний: світлий фон з контуром.
- Єдиний стиль для кольору, якості, профілів і вибору сторінок.
- Немає зміщення кнопок при перемиканні; стан aria-pressed синхронізується.
- Після ручного коригування інтенсивності/контрасту показано «Настроено вручную».
- Обрання профілю інтенсивності відновлює його рівень і встановлює нейтральний контраст 0.

Встановлення у PowerShell (у корені проєкту):
  Set-Location "G:\IT\Node.JS\canon_TS5350i"
  Expand-Archive -LiteralPath ".\Canon-Studio-UI-Controls-Fix.zip" -DestinationPath "." -Force

Перезапустіть Canon Studio і натисніть Ctrl+F5 у Chrome.

Архів містить лише сім змінених/нових файлів проєкту (HTML, CSS, JS та тест).
Він не перезаписує сервер, package.json, Start-Canon-Studio.cmd чи Start-Canon-Studio.ps1.
Тести: node --test tests/frontend.test.mjs tests/ui-controls.test.mjs
